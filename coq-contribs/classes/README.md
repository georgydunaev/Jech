# Classes and Theorems Documentation

## Overview
This directory contains experiments with classes and many theorems about them in the Coq formalization of set theory.

## Contents
- `Classes.v`: Definitions and basic properties of classes.
- `Class_Theorems.v`: Many theorems about classes.

## Dependencies
- Coq version 8.13 or later
- MathComp library

## Usage
To use this library, you need to have Coq and MathComp installed. You can then compile the `.v` files using the Coq compiler.
