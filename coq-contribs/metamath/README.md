# Metamath Theorems Translation Documentation

## Overview
This directory contains the translation of Metamath theorems into Coq formalization.

## Contents
- `Metamath_Translation.v`: Translation of Metamath theorems into Coq.

## Dependencies
- Coq version 8.13 or later
- MathComp library

## Usage
To use this library, you need to have Coq and MathComp installed. You can then compile the `.v` files using the Coq compiler.
