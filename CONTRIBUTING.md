# Contributing to Jech

## How to Contribute

### Reporting Issues

1. **Check Existing Issues**: Before creating a new issue, please check if it has already been reported.
2. **Create a New Issue**: If the issue is not already reported, create a new issue in the GitHub repository.
3. **Provide Details**: Include a clear and concise description of the issue, steps to reproduce, and any relevant screenshots or code snippets.

### Creating Pull Requests

1. **Fork the Repository**: Fork the Jech repository to your GitHub account.
2. **Clone the Repository**: Clone the forked repository to your local machine.
3. **Create a New Branch**: Create a new branch for your changes.
4. **Make Changes**: Make your changes to the codebase.
5. **Write Tests**: Write tests to cover your changes.
6. **Run Tests**: Run the test suite to ensure all tests pass.
7. **Submit a Pull Request**: Submit a pull request with a clear description of your changes.

### Code Style Guidelines

- Follow the existing code style and conventions used in the project.
- Use meaningful variable and function names.
- Write clear and concise comments to explain complex logic.
- Ensure your code is well-documented.
- Use type hints to improve code readability and maintainability.
- Follow the PEP 8 style guide for Python code.
- Use docstrings to document functions, classes, and modules.
- Keep lines of code within 79 characters to improve readability.

### Running Tests

To run the test suite, use the following command:

```bash
python -m pytest
```

### Review Process

- All pull requests will be reviewed by the maintainers.
- Address any feedback or requested changes.
- Once approved, your pull request will be merged into the main repository.

## Commit Message Guidelines

- Use clear and concise commit messages that describe the changes made.
- Start the commit message with a verb in the imperative mood (e.g., "Add", "Fix", "Update").
- Keep the commit message within 50 characters to improve readability.
- Provide additional details in the commit message body if necessary.
